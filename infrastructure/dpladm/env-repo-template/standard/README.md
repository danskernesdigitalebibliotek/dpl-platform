# Core Test site "${LAGOON_PROJECT_NAME}"

This is the environment repository for the Core Test site ${LAGOON_PROJECT_NAME}

## Environment variables

The application services CMS, GO and BNF depend on environment variables. This
list is incomplete — please add to it as you go.

Two things are easy to conflate, so they are kept apart below:

- **Origin** — where the value is set (a provisioning script, a human, Lagoon).
- **Transport** — how it reaches the GO build. Lagoon propagates project-level
  build and global variables as build-args, but only those declared as `ARG` in
  this repository's `lagoon/node.dockerfile` actually reach the Next.js build.

Each variable below names where it is _read_, so the claim can be checked rather
than assumed. Paths are relative to the `dpl-web` repository unless noted.
Verified 2026-07-31.

### Declared as ARG in this repository's lagoon/node.dockerfile

Only these reach the GO build. Confirm against the dockerfile in this repository
rather than trusting this list — env repositories drift from the template, and
older ones still declare superseded names such as `NEXT_PUBLIC_APP_URL`.

- `DPL_GO_BASE_URL` — read in `go/lib/config/env.ts` and, on the CMS side, in
  `cms/web/modules/custom/dpl_go/src/GoSite.php`.
- `DPL_CMS_BASE_URL` — read in `go/lib/config/env.ts`; used for the Next.js
  image `remotePatterns` allowlist and the GraphQL endpoint.
- `DRUPAL_REVALIDATE_SECRET` — read in `go/lib/config/env.ts` (guards
  `GET /cache/revalidate`) and in `cms/.../dpl_go/dpl_go.deploy.php`.
- `GO_SESSION_SECRET` — read in `go/lib/config/env.ts`; seals the
  `iron-session` cookie.
- `NEXT_PUBLIC_GO_GRAPHQL_CONSUMER_USER_PASSWORD` — read in
  `go/lib/config/env.ts` and `cms/.../dpl_consumers/dpl_consumers.module`.
- `UNLILOGIN_PUBHUB_RETAILER_ID` — read in `go/lib/config/env.ts`; sent as
  `retailerid` in Publizon SOAP requests (`go/lib/helpers/publizon.ts`).
- `UNLILOGIN_PUBHUB_RETAILER_KEY_CODE` — as above, MD5-hashed into
  `retailerkeycode`.

`LAGOON_ENVIRONMENT`, `LAGOON_PROJECT`, `LAGOON_ROUTE` and `LAGOON_ROUTES` are
also declared, and are provided by Lagoon rather than set here.

### Generated by infrastructure/task/scripts/create-update-node-env-variables.mjs

Unique per project.

- `GO_SESSION_SECRET` — reader as above.

### Generated by infrastructure/task/scripts/create-go-and-bnf-consumer-and-secrets.mjs

The values are identical across projects.

- `BNF_GRAPHQL_CONSUMER_SECRET` — required by
  `cms/.../dpl_consumers/dpl_consumers.module`, which throws if it is unset.
- `BNF_GRAPHQL_CONSUMER_USER_PASSWORD` — same module; also used for the Basic
  auth header in `cms/web/modules/custom/bnf/src/SailorEndpointConfig.php`.
- `GO_GRAPHQL_CONSUMER_SECRET` — same module, also required.
- `DRUPAL_REVALIDATE_SECRET` — reader as above.
- `NEXT_PUBLIC_GO_GRAPHQL_CONSUMER_USER_PASSWORD` — reader as above.

Note the `NEXT_PUBLIC_` prefix. The unprefixed
`GO_GRAPHQL_CONSUMER_USER_PASSWORD` is **not** provisioned and is never read
from the environment: it exists only as an internal config key in
`go/lib/config/env.ts`, sourced from the prefixed variable. Older projects still
carry it as a leftover Lagoon variable.

### Set by hand in the DPL CMS config form at <https://dpl-cms-project-url.tld/admin/config/services/>

- `UNILOGIN_CLIENT_SECRET` — read in `go/lib/config/env.ts` and applied to
  `dpl_unilogin.settings` in `cms/assets/local.settings.php` and
  `cms/assets/development.settings.php`.
- `UNILOGIN_MUNICIPALITY_ID` — same readers.
- `UNLILOGIN_PUBHUB_RETAILER_KEY_CODE` — reader as above. Beware the spelling:
  GO reads the misspelled `UNLILOGIN_` form, while the CMS settings files read
  the correctly spelled `UNILOGIN_PUBHUB_RETAILER_KEY_CODE`. Only the misspelled
  name is provisioned as a Lagoon variable.

### Documented previously but not read anywhere

These have no reader in `dpl-platform` or `dpl-web` (checked including
gitignored composer and contrib code). They are safe to stop setting.

- `BNF_SERVER_GRAPHQL_ENDPOINT` — the BNF GraphQL endpoint is hardcoded in
  `cms/web/modules/custom/bnf/sailor.php`.
- `UNLILOGIN_SERVICES_WS_USER` and `UNLILOGIN_SERVICES_WS_PASSWORD` —
  superseded by certificate-based auth (`UNILOGIN_WS_UDBYDERSYSTEM_ID`,
  `UNILOGIN_WS_PRIVATE_KEY`, `UNILOGIN_WS_PUBLIC_CERT`), which GO reads in
  `go/app/(routes)/auth/callback/unilogin/requests.ts`.
- `NEXT_PUBLIC_GRAPHQL_SCHEMA_ENDPOINT_FBI`, `UNILOGIN_API_URL` and
  `NEXT_PUBLIC_PUBHUB_BASE_URL` — present only in `.env` files and docs.
- `NEXT_PUBLIC_GRAPHQL_BASIC_TOKEN_DPL_CMS` — legacy pre-encoded Basic auth
  token; GO computes the token at runtime from the consumer username and
  password instead.
